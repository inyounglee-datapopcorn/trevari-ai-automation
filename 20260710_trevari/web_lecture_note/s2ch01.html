실습 흐름
채팅창에 질문이 들어온다(Chat Trigger) → AI Agent가 질문을 읽는다 → 연결한 내 업무 자료를 찾아본다 → 답을 만들어 돌려준다.
이 흐름이 3T입니다. Trigger는 "질문이 들어올 때", Task는 "자료를 찾아 답 만들기", Target은 "채팅창에 답 보내기"입니다.
핵심 용어사전
1. 3T 프레임워크

모든 업무를 Trigger(언제 시작하나), Task(무엇을 처리하나), Target(어디로 보내나) 세 칸으로 나누어 보는 책의 설계 방법입니다.

2. 워크플로우(Workflow)

여러 단계를 이어 붙인 자동화 한 세트입니다. n8n 화면의 캔버스 하나가 워크플로우 하나입니다.

3. 노드(Node)

워크플로우의 한 단계입니다. 블록처럼 하나씩 꺼내 선으로 이어 붙입니다.

4. 트리거(Trigger)

워크플로우를 시작시키는 신호입니다. 정해진 시간이 되었을 때, 채팅 메시지가 들어왔을 때 같은 것입니다.

5. 게시(Publish)

만든 워크플로우를 켜 두는 것입니다. 게시하기 전에는 직접 실행해 볼 때만 돌아갑니다.

6. 스티키 노트(Sticky Note)

캔버스에 붙이는 메모입니다. 큰 흐름을 먼저 글로 적어 두면 노드를 고를 때 길을 잃지 않습니다.

7. Chat Trigger

채팅창으로 들어온 메시지를 받아 워크플로우를 시작하는 노드입니다.

8. AI Agent 노드

질문을 이해하고, 연결된 AI 모델과 자료를 골라 써서 답을 만들어 내는 노드입니다. 챗봇의 두뇌 역할을 합니다.

9. 프롬프트(Prompt)

AI에게 주는 지시문입니다. "누구에게, 어떤 말투로, 무엇을 근거로 답하라"를 적어 줍니다. 엉뚱한 답은 대부분 여기를 고치면서 잡습니다.

10. API

프로그램끼리 데이터를 주고받는 창구입니다. 책에서는 날씨와 농산물 가격 같은 외부 데이터를 가져올 때 씁니다.

11. 웹훅(Webhook)

어떤 일이 생겼을 때 정해진 주소로 알려 주는 방식입니다. 다른 서비스가 n8n을 깨우는 문이 됩니다.

12. 자격 증명(Credential)

Gmail, AI 모델 같은 서비스를 연결할 때 쓰는 로그인 정보와 API 키입니다. 남에게 보여 주거나 화면에 공유하지 않습니다.

WHY · 기준 먼저 잡기

HOW · 구조 읽는 눈

AI가 99%를 짜줘도 마지막 1% 오류·통제·책임은 사람이 맡아야 하기에 n8n으로 흐름의 해부도를 익힙니다.

WHAT · 챗봇 3요소

커스텀 AI 챗봇은 Model(두뇌) · Memory(기억) · Tool(도구)의 조합이며, Publish(게시)를 켜야 자동 실행됩니다.

1. 오프닝과 모인 사람들의 출발점

2. 클럽장의 메시지 ① — "AI를 왜 쓰는지, 나만의 기준부터 잡기"

AI 자동화는 시간과 비용을 줄여줄 뿐 아니라, 매일 반복되던 무의미한 작업에서 오는 심리적 스트레스를 덜어줍니다. 하지만 "지금 못 따라가면 뒤처진다"는 공포 마케팅에 휘둘려 시작하면, 정작 아낀 시간에 다른 업무가 3~5배 더 쌓여 번아웃이 오고 금방 원래 방식으로 돌아가기 쉽습니다.

"More Sleep, More Sunshine, More Love" (+ More Money)
클럽장이 AI를 쓰는 기준은 주말은 쉬고, 점심 뒤 1시간은 햇빛을 보며 산책하고, 가족·이웃과 시간을 보내는 것입니다. 회사나 유행이 아니라, 내가 진짜 지키고 싶은 삶과 목표를 먼저 정해두어야 AI 공부를 끝까지 이어갈 수 있습니다.

3. 클럽장의 메시지 ② — "클로드 코드 시대에도 왜 n8n을 배울까?"

요즘은 Claude Code·Codex 같은 에이전트에게 말만 하면 워크플로우와 웹 서비스까지 뚝딱 만들어 줍니다. 그런데도 n8n(nodemation에서 n과 n 사이 8글자를 줄인 이름, 최근 v3 리브랜딩)을 익혀야 하는 이유는 AI가 만든 결과를 읽고 통제하기 위해서입니다.

자율주행차 (Claude Code·생성형 AI)

목적지까지 99%를 대신 데려다주지만, 확률적(Probabilistic)으로 동작해 같은 요청에도 답이 달라질 수 있고 골목길·예외 상황의 마지막 1%는 직접 운전할 줄 알아야 합니다.

설계도와 계기판 (n8n 워크플로우)

단계가 눈으로 보이고 결정론적(Deterministic) 규칙을 강제할 수 있습니다. 오늘 되던 자동화가 내일 멈췄을 때 어느 노드가 고장 났는지 해부도처럼 찾아 고치는 힘을 길러줍니다.

실무 자동화에서 놓치지 말아야 할 안전장치: Human-in-the-loop

AI는 대신 책임을 져주지 않습니다. 고객 문의 분류·문서 초안·결제 준비처럼 중요한 일은 AI가 초안을 만든 뒤 최종 발송·승인 버튼은 사람이 누르는 구조(Human-in-the-loop)로 설계해야 안전합니다. 100% 손으로 노드를 짜지 않더라도, AI가 짜준 흐름을 검수할 수 있는 로직 이해력이 핵심입니다.

4. 북토크 토론 — "자동화가 다 해준 뒤, 남는 일과 맡길 수 없는 일"

  • 실행은 AI에게, '기획·감각·책임'은 사람에게: 영상 편집이나 초안 작성 시간이 며칠에서 몇 분으로 줄어든 뒤에는, 남는 시간에 책을 읽고 사람을 만나 경험을 쌓으며 "무엇을 어떤 관점으로 만들 것인가"를 기획하는 힘이 진짜 경쟁력이 된다는 경험이 공유됐습니다. 내용증명 초안처럼 AI가 거침없이 강한 문구를 써줄 때도 수위 조절과 최종 책임은 사람 몫이라는 점에 공감했습니다.
  • 규제·보안과 AI 활용 양극화: 개인정보·민감 데이터를 AI가 다루지 못하게 하는 법적·사내 보안 기준과, 세무사 시험 AI 안경 부정행위 논란처럼 기술을 따라가지 못하는 제도의 공백, 그리고 요금제 고가화에 따른 활용 격차에 대한 고민을 나눴습니다.
  • 능동적(Proactive) AI 비서와 하네스(Harness): 질문해야 답하던 챗봇을 넘어 일정·맥락을 보고 먼저 제안하는 AI 비서(피클·Dots·Muse·Grok Bot 등)와 위험 행동을 막는 안전장치(하네스)를 살펴봤습니다. 2~3주마다 쿠팡 장바구니에 우유·시리얼을 미리 담아두는 루틴과 세금 납부 전 잔고 확인 실험, 그리고 파트너님이 공유한 브라우저 에이전트(Aside)+카카오톡 MCP 기반 세무 자료 자동 분류(검수 시간 대폭 단축) 및 AI 음성 보고 브리핑 사례는 AI를 어디까지 위임할 수 있는지 생생히 보여주었습니다.
  • 세탁기의 역설: 세탁기가 발명됐지만 빨래를 더 자주 하게 되어 가사 시간이 줄지 않았듯, AI로 처리 속도가 빨라질수록 인력을 늘리기보다 하루에 돌리는 일의 가짓수가 늘어(2~3건 → 10건) 더 바빠지는 현상과 신입 채용 축소 체감도 이야기했습니다.
  • 끝내 AI에게 못 맡기는 세 가지: ① 금융·계좌·통합 로그인: 계좌 조회나 모든 서비스 로그인 권한을 넘기는 보안·분실 우려 ② 가족·돌봄·인간관계: AI 캐릭터 챗 시장이나 영화 A.I.·Her, 어머니 레시피를 재현한 로보틱스 사례를 이야기하며, 감정을 흉내 낼 수 있어도 배우자·자녀·부모와의 진짜 관계는 대신할 수 없다는 결론을 나눴습니다 ③ 깊이 있는 독서와 사유의 과정: 요약만 보면 문맥과 생각하는 힘이 사라진다는 의견과 함께, 반대로 대화·회의를 스마트폰 녹음이나 클로바노트·다글로·티로·Plaud Note·옵시디언+MCP로 기록해 나만의 자산으로 쌓는 방법도 공유했습니다.

5. n8n & AI Agent 챗봇 원리 시연 핵심

  • 3T 프레임워크와 노코드 로직: 모든 자동화는 Trigger(언제) → Task(무엇을) → Target(어디로)로 나눕니다. 코딩 문법을 외우는 대신, '땅콩버터 젤리 샌드위치 만들기'처럼 컴퓨터가 오해하지 않도록 절차를 빠짐없이 논리적으로 쪼개는 사고방식이 노코드의 본질입니다.
  • 테스트 실행 vs Publish(게시): 캔버스에서 누르는 Execute Workflow는 테스트용입니다. 시간 기반(Schedule Trigger — 예: 3시간마다 체크) 또는 이벤트 기반(Chat·Webhook) 트리거를 연결한 뒤 반드시 Publish(게시)를 켜야 내가 자는 새벽에도 자동으로 돌아갑니다.
  • 실무 흐름 시연: 쿠팡·네이버 스마트스토어 신규 주문 알림 워크플로우(주기 체크·중복 방지·슬랙 전송)와 샘플 주문 데이터에서 5만 원 이상만 걸러내는 Filter 노드를 통해 Input → Output 데이터 흐름을 확인했습니다.

커스텀 AI 챗봇(Chat Trigger + AI Agent)을 구성하는 3요소

ChatGPT는 완성된 서비스 이름, GPT는 두뇌(모델) 이름입니다. n8n에서는 두뇌·기억·도구를 직접 조립해 우리 회사 자료와 보안 기준에 맞는 별도 환경(로컬·자체 서버 등)에서 전용 챗봇 뼈대를 5분 만에 만들 수 있습니다.

① Model (두뇌) 업무 난이도·비용에 맞춰 모델을 고르고, System Message(Role · Task · Context · Format)로 한국어 응답과 규칙을 강제합니다.
② Memory (기억) 메모리를 빼면 바로 앞 대화("내 이름은 팝콘")도 잊는 실험을 통해, 대화 맥락을 이어가려면 기억 노드가 필수임을 확인했습니다.
③ Tool (도구) 날짜 정보나 계산기(Calculator)·검색 도구 없이 모델만 두면 현재 시점이나 정밀 계산에 취약하므로 필요한 도구를 연결해 줍니다.

6. 다음 모임(12/11) 전까지 & 앞으로의 여정

  1. 데모 서버에서 1~4단계 복습하기: n8n 데모 서버에 접속해 1~4단계 챗봇·주문 템플릿을 직접 실행해 보고, 내 반복 업무 1개를 3T로 나눠 스케치해 보세요. (※ 공용 서버이므로 실제 업무 계정·API 키·사내 비밀·개인정보는 넣지 마세요.)
  2. 2회차 실습 준비와 멤버 피드백 반영: 다음 모임부터는 개인 노트북 지참·충전 후 단계별 따라 하기 비중을 높이고, 실제 유즈케이스(공모전·업무 자동화·툴 비교)와 API/MCP 기초 개념도 함께 보강할 예정입니다.
  3. 2~4회차 커리큘럼 예고: 2회차(12/11) 『진짜 노동』 + 24시간 AI 비서(피클·Dots·Muse 등 비교·세팅) → 3회차(1/8) 「이제 직원 급여도 AI가 보냅니다」 + 브라우저 AI(Aside) → 4회차(2/12) 『파타고니아, 파도가 칠 때는 서핑을』 + AI 15초 숏폼(다수 자동화 채널 사례·AI 영상 제작 비용과 기획 현실).
  4. 모임 사이 혜택 챙기기: 카톡방의 번추위(월간 번개 모임 추진)에 가볍게 참여해 보시고, 개별 업무·도입 고민이 있다면 30분 무료 1:1 상담과 카톡방 공지의 인프런 강의 90% 할인 쿠폰(연말까지 등록, 등록 후 24시간 내 사용)을 적극 활용해 주세요.
